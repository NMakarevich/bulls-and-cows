# Структуры данных и алгоритмы
## 1. Состояние игры
Для состояния игры используется объект, содержащий `base`и `length` для текущей игры, сгенерированный `secret` и историю попыток в виде массива объектов, включающих предполагаемое число, количество bulls и cows.
Использование объектов для конфига игры и истории попыток обеспечивает быстрый доступ к необходимым параметрам.
## 2. Алгоритм `evaluateGuess`
Алгоритм реализован через метод `reduce`аргументами которого выступает объект-аккумулятор `{ bulls, cows }`, текущий символ и индекс символа.
В первую очередь проверяется равенство текущего символа из `guess`и символом из `secret` с тем же индексом. В случае равенства увеличивается счетчик `bulls.`
Если символы не равны, производится проверка, есть ли этот символ в `secret`. Если есть - увеличивается счетчик `cows`, иначе ничего не делается. 
В результате прохода по всем символам из `guess ` возвращается объект, содержащий число `bulls` и `cows`.
## 3. Алгоритм `countPossibleSecrets`
Алгоритм реализован в виде рекурсивной функции, которая принимает на вход количество чисел в выбранной системе счисления и выбранную длину секрета. 
Функция выполняет перемножение количества возможных символов на эту же функцию, принимающую на вход аргументы, уменьшенные на 1, до тех пор, 
пока длина не достигнет 0 - в этот момент функция возвращает 1 и происходит выход из рекурсии и возвращается результат перемножения.
# Сложность
## 1. generateSecret
Функция содержит один цикл `for`(сложность O(n)), внутри которого выполняется метод `splice` (сложность до O(n) в случае удаления первого элемента).
Таким образом общая сложность функции не превышает O(n<sup>2</sup>).
## 2. evaluateGuess
Функция содержит один метод `reduce`, сложность которого O(n), соответственно сложность функции O(n).
## 3. isValidGuess
Функция содержит внутреннюю функцию createDigitalValidator, возвращающая функцию, внутри которой вызывается метод `includes`, сложность которого до O(n).
Также внутри функции есть цикл `for`со сложностью O(n). Результирующая сложность до O(n<sup>2</sup>).
## 4. countPossibleSecrets
Функция содержит рекурсивную функцию со сложностью от O(n) до O(n-1)..O(1). Соответственно сложность функции O(n).
